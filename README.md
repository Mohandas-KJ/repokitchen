# 🍳 RepoKitchen

**Official sources. Fresh installs.**

RepoKitchen is a lightweight Linux CLI that simplifies software repository setup and installation on Ubuntu and Debian.

Instead of searching the web for repository URLs, signing keys, and installation commands, users can select their software and let RepoKitchen handle the process.

## ✨ Features

- 📦 Categorized software catalog
- 🔑 Repository and signing-key configuration
- 🖥️ Automatic installation or manual command display
- 🐧 Ubuntu and Debian support
- 🛡️ Security-focused installation recipes using official sources

## 🛠️ Initial Software

- Jenkins
- OpenNebula
- Apache Hadoop

Under active development.

Make installing popular Linux software simpler, safer, and more consistent.
